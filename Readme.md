# Student Performance Analysis Using Machine Learning

## Overview

This project focuses on analyzing student performance using various Machine Learning algorithms. It covers data preprocessing, regression, classification, clustering, and predictive modelling using Python.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Practical Implementation

The project covers 15 practicals, including Linear Regression, Logistic Regression, PCA, Naive Bayes, SVM, K-Means Clustering, Hierarchical Clustering, Decision Tree, Random Forest, and Artificial Neural Networks.
